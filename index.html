Frequently asked questions

Are there setup or monthly fees?

No. CRUDPay charges only on successful transactions. No monthly, setup, or maintenance fees on Starter and Growth plans.

When do I receive my settlement?

Starter: T+2. Growth: Next business day or instant. Enterprise: Custom settlement cycles based on your volume.

Which currencies do you support?

135+ currencies across 80+ countries. INR, USD, EUR, BRL, MXN, and all major cross-border corridors natively supported.

Can I upgrade my plan later?

Yes, at any time. Changes apply from the next billing cycle. No penalties or lock-ins on any plan.

Quickstart Guide

Get CRUDPay integrated in under 10 minutes. This guide walks you through creating your first payment using our REST API.

Before you start: Create a CRUDPay account and retrieve your API keys from Settings → API Keys.

1. Install the SDK

Official SDKs for Node.js, Python, Ruby, PHP, Java, and Go.

npm install crudpay-node

2. Initialize the client

const CRUDPay = require('crudpay-node');
const client = new CRUDPay('YOUR_API_KEY');

3. Create your first payment

const payment = await client.payments.create({
  amount: 50000,
  currency: 'INR',
  payment_method: 'upi',
  merchant_id: 'mrc_xxxx',
  customer: {
    name: 'Priya Sharma',
    email: 'priya@example.com'
  }
});

4. Handle the response

On success you receive a payment object with status: created. Listen for the payment.captured webhook to confirm funds.

Next steps

  • Set up webhooks for real-time events
  • Explore all payment methods
  • Configure fraud detection rules
